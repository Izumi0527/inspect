## ⚡ 快速启动

### 1. 安装依赖
```bash
cd backend
uv sync  # 或者 pip install -r requirements.txt
```

### 2. 配置数据库、Redis和InfluxDB
```bash
# 启动PostgreSQL（使用Docker）
docker run -d --name postgres-inspect \
  -e POSTGRES_DB=inspect_db \
  -e POSTGRES_USER=postgres \
  -e POSTGRES_PASSWORD=password \
  -p 5432:5432 \
  postgres:13

# 启动Redis（使用Docker）
docker run -d --name redis-inspect \
  -p 6379:6379 \
  redis:7-alpine

# 启动InfluxDB（可选，使用Docker）
docker run -d --name influxdb-inspect \
  -p 8086:8086 \
  -e DOCKER_INFLUXDB_INIT_MODE=setup \
  -e DOCKER_INFLUXDB_INIT_USERNAME=admin \
  -e DOCKER_INFLUXDB_INIT_PASSWORD=password123 \
  -e DOCKER_INFLUXDB_INIT_ORG=inspect-org \
  -e DOCKER_INFLUXDB_INIT_BUCKET=monitoring \
  -e DOCKER_INFLUXDB_INIT_ADMIN_TOKEN=inspect-token-123456789 \
  influxdb:2.7
```

### 3. 配置环境变量
```bash
# 复制环境配置模板
cp .env.template .env

# 编辑连接信息，主要配置：
# 基础配置
# DEBUG=true
# SECRET_KEY=your-super-secret-key-change-in-production

# 数据库配置
# DATABASE_URL=postgresql+asyncpg://postgres:password@localhost:5432/inspect_db

# Redis缓存配置
# REDIS_URL=redis://localhost:6379/0

# InfluxDB时序数据库配置
# INFLUXDB_URL=http://localhost:8086
# INFLUXDB_TOKEN=inspect-token-123456789
# INFLUXDB_ORG=inspect-org
# INFLUXDB_BUCKET=monitoring

# 邮件通知配置（可选）
# SMTP_HOST=smtp.example.com
# SMTP_PORT=587
# SMTP_USER=your-email@example.com
# SMTP_PASSWORD=your-email-password
# FROM_EMAIL=noreply@inspect.local
```

### 4. 测试各组件连接（可选）
```bash
# 测试Redis缓存集成
python test_redis_cache.py

# 测试InfluxDB时序数据库
python test_influxdb.py

# 测试WebSocket实时通信
python test_websocket.py
```

### 5. 启动后端服务
```bash
# 方法1：使用启动脚本（推荐）
python start_backend.py

# 方法2：直接启动
python -m src.main

# 方法3：使用uvicorn
uvicorn src.main:app --host 0.0.0.0 --port 8000 --reload
```

## 📋 API测试示例

### 1. 用户登录
```bash
curl -X POST "http://localhost:8000/api/v1/auth/login" \
     -H "Content-Type: application/json" \
     -d '{"username":"admin","password":"Admin123!"}'
```

### 2. 获取设备列表
```bash
# 先获取访问令牌，然后：
curl -X GET "http://localhost:8000/api/v1/devices/" \
     -H "Authorization: Bearer <access_token>"
```

### 3. 启动网络扫描
```bash
curl -X POST "http://localhost:8000/api/v1/devices/scan" \
     -H "Authorization: Bearer <access_token>" \
     -H "Content-Type: application/json" \
     -d '{"target_network":"192.168.1.0/24","scan_type":"ping"}'
```
