## 📱 PWA 离线能力

### Service Worker 策略
- **Cache First**: 静态资源优先使用缓存
- **Network First**: API请求优先使用网络
- **Stale While Revalidate**: HTML文档后台更新

### 离线功能
- 📦 **资源缓存**: 关键资源离线可用
- 🔄 **后台同步**: 网络恢复时自动同步
- 📲 **推送通知**: 支持消息推送
- 🏠 **桌面安装**: PWA原生应用体验
